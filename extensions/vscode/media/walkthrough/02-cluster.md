## 五个分区，一眼看清

侧栏 **ComputeDeck** 视图按使用频率组织：

- **集群总览** — 健康评分、在线 / 离线、GPU 空闲 / 占用、排队、租约、入口分层
- **节点** — 每台机器的状态、`空闲/总数`、最后成功探活；异常会标红
- **Job** — 已安装任务插件，展开后行内可启动 / 重启 / 停止
- **队列与租约** — pending 工作负载和节点占用
- **入口** — Edge / LiteLLM / nginx；检测到重复节点 LB 时会置顶告警
- **操作** — 自检、探活、SSH、诊断、部署、腾空、MCP 的快捷入口

状态栏左侧常驻：`CD 4/4 节点 · 12/16 空闲`。有离线节点时变成感叹号，点击直接打开 Web 看板。

> 插件不硬编码节点名或 Job 名，全部来自控制面 API；集群变了只需刷新。

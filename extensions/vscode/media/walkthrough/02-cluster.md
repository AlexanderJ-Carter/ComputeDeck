## 侧栏导航 + 工作台窗口

侧栏 **ComputeDeck** 只做导航，避免塞满：

- **打开工作台** — 编辑器旁独立面板：KPI、小助手 / MCP、监管公告、自检 / 探活 / 部署等
- **集群总览**（默认折叠）— 健康评分、在线 / 离线、GPU、排队、租约
- **节点** — 每台机器的状态、`空闲/总数`；行内终端 / 诊断 / 腾空
- **Job** — 已安装任务插件；行内启动 / 重启 / 停止
- **队列与租约** · **入口** — pending、租约、Edge / LiteLLM / nginx

状态栏左侧常驻：`CD 4/4 节点 · 12/16 空闲`。点击打开工作台；完整看板用「打开 Web 控制面」（优先 Simple Browser）。

> 插件不硬编码节点名或 Job 名，全部来自控制面 API；集群变了只需刷新。

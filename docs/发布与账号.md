## 需要你提供的账号

### 1. VS Code Marketplace（官方 VS Code）

要发布到官方市场，需要一个**发布者（publisher）**。当前 `package.json` 里写的是：

```json
"publisher": "computedeck"
```

你需要：

1. 用 Microsoft 账号登录 <https://marketplace.visualstudio.com/manage>；
2. 创建一个发布者，ID 填 `computedeck`（如果已被占用，告诉我你想用的 ID，我改 `package.json`）；
3. 在发布者设置里创建 **Trusted Publishing** 策略：
   - Policy name：`ComputeDeck release`
   - Repository owner：`AlexanderJ-Carter`
   - Repository：`ComputeDeck`
   - Workflow：`vscode-publish.yml`
   - Environment：留空
4. 不需要把 PAT 发给我。OIDC 方式不需要长期 Secret。

然后运行工作流 `.github/workflows/vscode-publish.yml`，`registry` 选 `marketplace` 或 `both`，输入 `publish`。

> 旧的 Azure DevOps PAT 方式在 2026-12-01 停用。现在推荐上面的 OIDC；如果你只想先手动上传，也可以在 Publisher 管理页直接上传 VSIX。

### 2. Open VSX（Cursor / Windsurf / VSCodium / CodeLab）

1. 用 GitHub 登录 <https://open-vsx.org>；
2. 关联 Eclipse 账号，同意 Publisher Agreement；
3. Settings → Access Tokens 生成 Token；
4. 创建 / 认领命名空间 `computedeck`；
5. 把 Token 写成仓库 Secret：`OVSX_PAT`。

然后把 Token 给我时**不要贴在聊天里**，直接在 GitHub → Settings → Secrets and variables → Actions 新建 `OVSX_PAT`。创建好告诉我，我来跑工作流。

### 3. PyPI（可选，目前不建议）

- 发行名 `computedeck` 可用；`gpu-control` 已被一个无关项目占用。
- 当前仓库不是标准 Python 包布局（`uv build` 会失败），控制面依赖 `web/`、`playbooks/`、`jobs/` 等仓库资源。
- 要发 PyPI 需要先做包布局和路径解析重构；建议等 CLI 能脱离仓库目录运行后再做。
- 如果以后要做，需要 PyPI 账号 + 2FA + API Token；到时再用 Secret。

### 4. npm（不需要）

VS Code 扩展的安装单位是 VSIX，不是 npm 包；项目也没有需要作为 npm 库分发的 JS 运行时代码。发布到 npm 不会让编辑器直接安装，反而多一套版本和供应链维护。

### 5. GHCR / GitHub Release

已经使用 GitHub Actions 的 `GITHUB_TOKEN`，不需要额外账号或 Secret。GHCR 包需要在 Packages 设置里保持 Public（首次发布时确认一次）。

## 发版流程

```bash
# 1. 准备版本（会把产品、CLI、扩展版本收束到同一版本）
python scripts/prepare_release.py --version 1.3.1 --apply --check

# 2. 本地验收（可选）
./scripts/package_all.sh

# 3. 提交并打 tag
git add -A && git commit -m "chore: release 1.3.1"
git tag -a v1.3.1 -m "v1.3.1"
git push origin main && git push origin v1.3.1
```

tag 推送后自动触发：

- `Release`：GitHub Release、源码包、VSIX、GHCR 镜像
- `VS Code extension`：构建 VSIX artifact
- `Deploy site`：演示页 + `/docs/`
- `ci`：测试

扩展市场发布是**手动**工作流，不会因为 tag 自动上传，避免版本没验收就上架。

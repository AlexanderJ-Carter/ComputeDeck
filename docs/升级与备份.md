# 升级与备份

## 1. 需要备份什么

| 路径 | 是否必需 | 说明 |
|------|----------|------|
| `config/local/cluster.json` | ✅ | 集群/网关/鉴权 |
| `config/local/nodes.json` | ✅ | 节点、路径、SSH |
| `config/local/jobs/*.json` | ✅ | 自建 Job |
| `config/local/models.json` | ✅ | 模型登记 |
| `config/local/toolkits.json` | 可选 | 工具栈覆盖 |
| `config/local/secrets/` | ✅ | 密码 hash、session secret、API token、证书、HF token |
| `state/leases.json` / `queue.json` / `node_state.json` | 建议 | 调度状态 |
| `state/runlog.jsonl` | 可选 | 审计 |
| `snapshots/` | 可选 | GPU 快照 |
| `inventory.ini` / `resources.json` | 否 | 可重新生成 |

`config/local/` 与 `state/` 已在 gitignore 中，发布包用 `git archive` 即可保持干净。

## 2. 升级步骤

```bash
cd /opt/gpu-control

# 1) 停服务（systemd 方式）
sudo systemctl stop gpu-control-ui gpu-control-watchdog 2>/dev/null || true
# pid 文件方式
kill $(cat state/ui.pid) 2>/dev/null || true

# 2) 备份
STAMP=$(date +%Y%m%d-%H%M%S)
tar czf /backup/gpu-control-$STAMP.tgz config/local state/*.json state/runlog.jsonl

# 3) 更新代码
git fetch --tags
git checkout <tag-or-main>
uv pip install -r requirements.txt

# 4) 校验并启动
gpu-control doctor
gpu-control node render
sudo systemctl start gpu-control-ui gpu-control-watchdog
```

升级后建议：

```bash
gpu-control diagnose check
python -m unittest discover -s tests
python scripts/smoke_ui.py      # 需 UI 运行 + token
```

## 3. 回滚

```bash
sudo systemctl stop gpu-control-ui
git checkout <previous-tag>
uv pip install -r requirements.txt
# 如有必要恢复备份
tar xzf /backup/gpu-control-$STAMP.tgz -C /opt/gpu-control
sudo systemctl start gpu-control-ui
```

回滚前确认 `CHANGELOG.md` 中是否有不可逆的配置/状态迁移。

## 4. 状态兼容性

- `state/*.json` 由控制面自动创建；损坏文件会被移到 `*.corrupt-<ts>` 并使用安全默认值。
- 升级跨大版本时，先备份 `leases/queue/node_state`，重启后检查：
  ```bash
  gpu-control lease list
  gpu-control queue list
  gpu-control get nodes
  ```
- 如果 Job 字段新增（如 `runtime_dir` / `ports_per_node`），旧配置仍可运行，缺失字段用默认值。

## 5. 迁移到新主控

1. 新机安装依赖与 `.venv`；
2. 只复制 `config/local/`（含 secrets）与需要保留的 `state/*.json`；
3. `inventory.ini`、`resources.json`、`.venv`、`web/static/help/` 可在目标机重新生成，不必拷贝；
4. `gpu-control node render && doctor`；
5. 重新签发 API Token / 确认证书路径；
6. 启动 UI 与 watchdog。

## 6. 发布产物

```bash
git archive --format=tar.gz --prefix=gpu-control/ HEAD -o gpu-control.tgz
```

`git archive` 只包含被跟踪文件，不会带上 `config/local`、`state`、`inventory.ini` 等。
发布前按[生产部署 §6 检查清单](生产部署.md)逐项确认。

# 远程接入（Tailscale / Cloudflare）

完整角色与鉴权矩阵见 [接入拓扑与鉴权](接入拓扑与鉴权.md)。

控制面默认只监听 `127.0.0.1:8787`。**优先**本机访问、SSH 隧道或 IDE Remote SSH；只有需要集群外稳定入口时，再用本页的 `gpu-control remote`（只调用本机已安装并已登录的 `tailscale` / `cloudflared`，不内置密钥、不代管账号）。

```bash
# 笔记本 → 主控（日常推荐）
ssh -N -L 8787:127.0.0.1:8787 <control>
```

> 原则：默认推荐 **tailnet 内** 或 **Cloudflare Access 之后** 的接入。公网暴露（Funnel / Quick Tunnel）必须显式确认，且默认要求控制面已开启鉴权。配置 UI「远程接入」页会展示场景说明、状态芯片与计划输出。

## 1. 先看状态

```bash
gpu-control remote status
gpu-control remote plan                 # 自动推荐命令
gpu-control remote plan --mode tailscale-serve
```

配置 →「远程接入」分页展示检测结果、推荐模式与阻塞项；可在界面里选择模式（自动 / Tailscale serve / funnel / Cloudflare quick / tunnel）并填写暴露端口（默认取 `control.ui_port`）。

```json
{
  "tailscale": {"installed": true, "backend_state": "Running", "dns_name": "control.tailnet.ts.net"},
  "cloudflared": {"installed": false},
  "auth_enabled": true,
  "warnings": []
}
```

## 2. 四种模式

| 模式 | 暴露面 | 适用 | 命令 |
|------|--------|------|------|
| `tailscale-serve` | 仅 tailnet | 团队日常访问（推荐） | `tailscale serve --bg http://127.0.0.1:8787` |
| `tailscale-funnel` | 公网 | 临时对外演示；必须开鉴权 | `tailscale funnel --bg http://127.0.0.1:8787` |
| `cloudflared-quick` | 公网临时 URL | 5 分钟演示 | `cloudflared tunnel --url http://127.0.0.1:8787` |
| `cloudflared-tunnel` | 你的域名 | 长期稳定；建议配 Cloudflare Access | `cloudflared tunnel run computedeck` |

### Tailscale（推荐）

```bash
# 控制面主机
curl -fsSL https://tailscale.com/install.sh | sh
tailscale up

gpu-control remote up --mode tailscale-serve --confirm
# 等价于：tailscale serve --bg http://127.0.0.1:8787
```

访问 `https://<control>.<tailnet>.ts.net`。只对 tailnet 可见，不会上公网。

### Cloudflare 命名隧道 + Access（长期方案）

```bash
cloudflared tunnel login
cloudflared tunnel create computedeck
cloudflared tunnel route dns computedeck control.example.com
cloudflared tunnel run computedeck
```

在 Cloudflare Zero Trust → Access → Applications 里为该域名加策略（邮箱、Google、GitHub 等）。这样即使域名在公网，未登录也进不来。

> 命名隧道需要人工完成登录与 DNS 绑定；`remote up --mode cloudflared-tunnel` 会返回 `manual_setup_required` 并给出命令，而不是替你执行。

## 3. 安全清单

1. **先开鉴权**：`gpu-control auth set-password --generate --enable`（或 OIDC）。`remote plan` 在鉴权关闭且选择公网模式时会直接阻塞。
2. **公网优先 Cloudflare Access / Tailscale ACL**，不要把裸 `:8787` 直接映射到公网。
3. **Funnel / Quick Tunnel 只用于临时演示**；Quick Tunnel 的 URL 不固定，也没有 SLA。
4. 端口保持默认回环：`cluster.control.ui_host` 设 `0.0.0.0` 仅在明确需要局域网直连时使用。
5. 定期看 `gpu-control diagnose check` 与看板「公告」；鉴权关闭会被标记。

## 4. API / MCP

| 动作 | HTTP | MCP |
|------|------|-----|
| 状态 | `GET /api/remote` | `gc_remote(action="status")` |
| 计划 | `GET /api/remote?plan=1&mode=auto` | `gc_remote(action="plan")` |
| 启动 | `POST /api/remote/action {"action":"up","mode":"auto","confirm":true}` | `gc_remote(action="up", confirm=true)` |
| 关闭 | `POST /api/remote/action {"action":"down","confirm":true}` | `gc_remote(action="down", confirm=true)` |

UI 助手也可以发起 `gc_remote`；写操作会先进入确认卡，用户确认后才会执行。

## 5. 关闭

```bash
gpu-control remote down --confirm
# tailscale serve reset / funnel reset；结束由控制面托管的 cloudflared
```

关闭后回到 SSH 隧道方式，或重新 `tailscale up` 按需访问。

# 产品演示页的自定义域名

GitHub Pages 目前同时发布根路径的 [`demo/`](https://github.com/AlexanderJ-Carter/ComputeDeck/tree/main/demo) 演示页和 `/docs/` 手册，默认地址：

https://alexanderj-carter.github.io/ComputeDeck/

## 推荐域名

按优先级：

| 域名 | 说明 |
|------|------|
| **computedeck.dev** | 简短、好记，适合产品和开发者 |
| **computedeck.io** | 常见的技术产品域名 |
| **computedeck.com** | 适合作为长期官网 |
| **computedeck.cn** | 国内访问或备案时可用 |
| computedeck.ai | 想突出 AI / Agent 时可用，通常更贵 |

不建议再把 `gpu-control.*` 当作对外主域名，它和产品名 ComputeDeck 不一致。

子域示例（同一主域下）：

- `www.computedeck.dev` → 产品演示页  
- `docs.computedeck.dev` → 文档站（可以以后再部署）

## 绑定步骤（GitHub）

1. 在域名注册商添加 DNS：
   - **Apex**（`computedeck.dev`）：A 记录指向 GitHub Pages IP  
     `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153`  
     或按 GitHub 文档使用 ALIAS/ANAME（若注册商支持）。
   - **www**：CNAME → `alexanderj-carter.github.io`
2. 仓库 → Settings → Pages → Custom domain 填入域名，勾选 Enforce HTTPS。
3. 在 `demo/CNAME` 写入裸域名（可复制 `demo/CNAME.example`），提交推送，让 Pages 产物带上 CNAME。

```bash
cp demo/CNAME.example demo/CNAME
# 编辑为你的真实域名后提交
```

DNS 生效后访问 `https://你的域名/` 即可；仓库 README 里的演示页链接也可以换成自定义域名。

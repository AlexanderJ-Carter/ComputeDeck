# 宣传站自定义域名

GitHub Pages 当前发布目录为仓库根下的 [`demo/`](../demo/)，默认地址：

https://alexanderj-carter.github.io/ComputeDeck/

## 推荐域名

按优先级：

| 域名 | 说明 |
|------|------|
| **computedeck.dev** | 首选：短、好记、偏产品/开发者 |
| **computedeck.io** | 常见产品站后缀，备选 |
| **computedeck.com** | 品牌主域，适合长期官网 |
| **computedeck.cn** | 国内访问/备案场景可并行 |
| computedeck.ai | 强调 Agent 叙事时可用，通常更贵 |

不建议再用 `gpu-control.*` 做对外主品牌域名（与产品名 ComputeDeck 分裂）。

子域示例（同一主域下）：

- `www.computedeck.dev` → 宣传展板  
- `docs.computedeck.dev` → 日后 MkDocs（可选）

## 绑定步骤（GitHub）

1. 在域名注册商添加 DNS：
   - **Apex**（`computedeck.dev`）：A 记录指向 GitHub Pages IP  
     `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153`  
     或按 GitHub 文档使用 ALIAS/ANAME（若注册商支持）。
   - **www**：CNAME → `alexanderj-carter.github.io`
2. 仓库 → Settings → Pages → Custom domain 填入域名，勾选 Enforce HTTPS。
3. 在 `demo/CNAME` 写入裸域名（可复制 `demo/CNAME.example`），提交推送，让 Pages 产物带上 CNAME。

```bash
cp demo/CNAME.example demo/CNAME
# 编辑为你的真实域名后提交
```

DNS 生效后访问 `https://你的域名/` 即可；仓库 README 里的展板链接可再改成自定义域。

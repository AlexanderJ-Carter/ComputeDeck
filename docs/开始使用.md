# 开始使用 ComputeDeck

这份说明按界面上出现的位置来写，不需要先了解内部实现。

## 界面上的入口

| 位置 | 名称 | 用途 |
|------|------|------|
| 最左侧图标 | ComputeDeck | 打开插件侧栏 |
| 侧栏顶部 | 打开工作台 | 打开常用面板 |
| 侧栏中间 | 节点 / 任务 / 排队 / 入口 | 找机器和任务；每行右侧有快捷按钮 |
| 侧栏标题栏 | 刷新、工作台、怎么用、完整看板、五分钟上手 | 插件的主要入口都在这排图标里 |
| 底部状态栏 | `CD 2/4 节点 · 0/8 空闲` | 显示在线节点和空闲 GPU，点击打开工作台 |
| 中间窗口 | 工作台 | 空闲卡、公告，以及自检、部署等按钮 |
| 中间窗口 | 怎么用 | 连接方式和登录时机的说明 |
| 中间窗口 | 完整看板 | 完整的网页界面，包含图表和助手对话 |
| 侧栏 / 工作台 | 打开小助手 | 网页聊天；未配好时会引导配置 API |
| 命令面板 | 配置小助手 API | 填写模型地址、密钥、模型名 |
| 命令面板 | 注册给 AI 用的工具 | 给 Copilot 等调用集群命令 |
| 输出面板 | ComputeDeck | 自检、部署、配置结果等文字输出 |
| 命令面板 | 搜索 `ComputeDeck` | 列出插件提供的所有命令 |

## 多数情况：人在总控机上

1. 打开仓库，安装插件，然后重新加载窗口。
2. 点左侧的 **ComputeDeck**。如果能看到节点，说明已经连上；多数情况下不用输密码。
3. 点 **打开工作台**，可以看到空闲卡、公告和常用按钮。
4. 需要完整网页界面时，点 **打开完整看板**。如果没有打开，到 **怎么用** 里点「用浏览器打开」。

## 三类机器

| 名称 | 作用 | 你需要做什么 |
|------|------|--------------|
| 总控机 | 负责调度和网页 | 一般在这台机器上使用插件，不需要密码 |
| GPU 工作节点 | 实际运行任务 | 一般不用登录它们的网页 |
| 你的笔记本 | 不在总控机旁边时使用 | 先通过远程桌面、CodeLab 或 SSH 连到总控机，再按上面的步骤操作 |

## 哪些地方需要登录

- **侧栏、工作台**：在总控机上打开仓库时通常会自动登录。如果提示未连接，可以用「使用本机密钥」或「密码登录」。
- **完整看板**：第一次打开可能需要登录一次。
- **GPU 工作节点**：不需要输入网页密码。

## 小助手和 AI

| 你想做的事 | 怎么做 |
|------------|--------|
| 在网页里和小助手聊天 | 侧栏或工作台点 **打开小助手**；如果还没就绪，先 **配置小助手 API** |
| 修改模型地址或密钥 | 命令面板运行 **配置小助手 API**，或到大屏小助手页里改 |
| 让 Copilot 直接操作集群 | 运行 **注册给 AI 用的工具**（这和网页聊天不是同一件事） |

更细的接口说明见 [AI / MCP 接入](ai-接入.md)。

## 找不到入口时

在命令面板搜索 `ComputeDeck`，运行 **五分钟上手** 或 **怎么用**。

运维和鉴权细节见 [接入拓扑与鉴权](接入拓扑与鉴权.md)。

# 开始使用 ComputeDeck

这份说明按界面上出现的位置来写，不需要先了解内部实现。

## 界面上的入口

| 位置 | 名称 | 用途 |
|------|------|------|
| 最左侧图标 | ComputeDeck | 打开插件侧栏 |
| 侧栏顶部 | 打开工作台 | 打开常用面板 |
| 侧栏中间 | 节点 / 任务 / 排队 / 入口 | 找机器和任务；每行右侧有快捷按钮 |
| 侧栏标题栏 | 刷新、工作台、怎么用、完整看板、五分钟上手 | 插件的主要入口都在这排图标里 |
| 底部状态栏 | `2/4 节点 · 0/8 空闲` | 显示在线节点和空闲 GPU，点击打开工作台 |
| 中间窗口 | 工作台 | 空闲卡、公告，以及自检、部署等按钮 |
| 中间窗口 | 怎么用 | 连接方式和登录时机的说明 |
| 中间窗口 | 完整看板 | 完整的网页界面，包含图表和助手对话 |
| 侧栏、工作台 | 打开小助手 | 网页聊天；未配置时会引导配置 API |
| 命令面板 | 配置小助手 API | 填写模型地址、密钥、模型名 |
| 命令面板 | 注册给 AI 用的工具 | 给 Copilot 等调用集群命令 |
| 输出面板 | ComputeDeck | 自检、部署、配置结果等文字输出 |
| 命令面板 | 搜索 `ComputeDeck` | 列出插件提供的所有命令 |

## 多数情况：人在主控机上

1. 打开仓库，安装插件，然后重新加载窗口。
2. 点左侧的 **ComputeDeck**。如果能看到节点，说明已经连上；多数情况下不用输密码。
3. 点 **打开工作台**，可以看到空闲卡、公告和常用按钮。
4. 需要完整网页界面时，点 **打开完整看板**。如果没有打开，到 **怎么用** 里点「用浏览器打开」。

## 三类机器

| 名称 | 作用 | 你需要做什么 |
|------|------|--------------|
| 主控机 | 负责调度和网页 | 一般在这台机器上使用插件，不需要密码 |
| GPU 工作节点 | 实际运行任务 | 一般不用登录它们的网页 |
| 你的笔记本 | 不在主控机旁边时使用 | 先通过远程桌面、CodeLab 或 SSH 连到主控机，再按上面的步骤操作 |

## 哪些地方需要登录

| 你在哪 | 插件侧栏 / 工作台 | 完整看板网页 |
|--------|-------------------|--------------|
| 主控本机，`auth.mode=none` | 免密 | 免密 |
| 主控本机，password / OIDC | 自动读本机 Token，免密 | 从插件打开：自动换票据，免密；直接在浏览器输入网址：密码或 OIDC |
| 笔记本通过 SSH 隧道访问 | 需要 Token 或密码 | 隧道地址仍需密码 / OIDC；从主控上的插件打开则免密 |
| 团队内网 Tailscale | 需要 Token | 需要 tailnet 身份 + 控制面密码 / OIDC |
| 公网 Cloudflare | 需要 Token | 需要 Access + 控制面密码 / OIDC |
| GPU 工作节点 | 不用插件 | 不需要网页密码，只走 SSH |

插件在主控本机打开看板时，会先用本机 Token 换一张 **90 秒、一次性** 的登录票据，再让浏览器换 Session；所以不用再输密码。直接在浏览器里输入网址，仍然按上面的规则要求密码或 OIDC。

## 小助手和 AI

| 你想做的事 | 怎么做 |
|------------|--------|
| 在网页里和小助手聊天 | 侧栏或工作台点 **打开小助手**；如果还没就绪，先 **配置小助手 API** |
| 修改模型地址或密钥 | 命令面板运行 **配置小助手 API**，或在看板的小助手页面里修改 |
| 让 Copilot 直接操作集群 | 运行 **注册给 AI 用的工具**；它让编辑器 AI 调用集群命令，与网页小助手相互独立 |

更细的接口说明见 [AI / MCP 接入](ai-接入.md)。

## 找不到入口时

在命令面板搜索 `ComputeDeck`，运行 **五分钟上手** 或 **怎么用**。

运维和鉴权细节见 [接入拓扑与鉴权](接入拓扑与鉴权.md)。

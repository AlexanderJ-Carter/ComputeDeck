# 开始使用 ComputeDeck

不用先懂术语。按下面做就行。

## 界面上哪里干什么

| 位置 | 名字 | 干什么 |
|------|------|--------|
| 最左侧图标 | ComputeDeck | 打开插件侧栏 |
| 侧栏顶部 | 打开工作台 | 打开常用面板 |
| 侧栏中间 | 节点 / 任务 / 排队 / 入口 | 找机器和任务；点行上的小按钮即可 |
| 侧栏标题栏图标 | 刷新 · 工作台 · 怎么用 · 完整看板 · 五分钟上手 | 常用入口 |
| 底栏状态 | `CD 2/4 节点 · 0/8 空闲` | 一眼看健康；点击打开工作台 |
| 中间大窗口 | 工作台 | 空闲卡、公告、自检/部署等按钮 |
| 中间大窗口 | 怎么用 | 白话说明：怎么连、何时要密码 |
| 中间大窗口 | 完整看板 | 网页大屏（图表、小助手长对话） |
| 输出面板 | ComputeDeck | 自检、部署等文字结果 |
| 命令面板 | 搜 `ComputeDeck` | 所有命令 |

## 你在总控机上（最常见）

1. 打开这个仓库，装好插件，**重新加载窗口**。
2. 左侧点 **ComputeDeck**：能看到节点，就说明已经连上（多数情况不用输密码）。
3. 点 **打开工作台**：看空闲卡、公告、常用按钮。
4. 要点完整网页大屏：点 **打开完整看板**。打不开就到 **怎么用** 里点「用浏览器打开」。

## 三种机器

| 叫什么 | 是什么 | 你要做什么 |
|--------|--------|------------|
| 总控机 | 管调度和网页的那台 | 在这台用插件；一般免密 |
| GPU 干活机 | 真正跑模型的机器 | 不用单独登录网页 |
| 你的笔记本 | 人在外面时 | 先远程进到总控机，再按上面步骤 |

## 什么时候要登录？

- **侧栏 / 工作台**：在总控上打开仓库时，一般自动登录。提示未连接时，用「使用本机密钥」或「密码登录」。
- **完整大屏网页**：第一次可能要登一次。
- **GPU 干活机**：不用你输网页密码。

## 还不会？

命令面板搜 **ComputeDeck**，点 **五分钟上手** 或 **怎么用**。

运维 / 网络安全细节见 [接入拓扑与鉴权](接入拓扑与鉴权.md)。

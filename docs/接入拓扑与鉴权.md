# 接入拓扑与鉴权

> **第一次用？** 先看白话版：[开始使用](开始使用.md)。下面是给运维 / 排障看的细节。

本文约定主控 / 被控 / 远程访问 / 鉴权 / 插件。  
实现仍以 [安全加固](安全加固.md) · [远程接入](远程接入.md) · [VS Code 插件](vscode插件.md) · [打包与发布](打包与发布.md) 为准。

## 1. 拓扑角色

```text
┌──────────── 客户端 ────────────┐
│  浏览器 / VS Code·CodeLab / MCP Agent  │
└───────────────┬────────────────┘
                │  HTTP(S) · Bearer / Session / OIDC
                ▼
┌──────────── 主控 control ──────┐
│  UI :8787 · API · MCP · 调度/租约/入口  │
│  Ansible / SSH 出站到被控节点          │
└───────────────┬────────────────┘
                │  SSH（ansible_user / key）
                ▼
┌──────────── 被控节点 workers ──┐
│  GPU · nvidia-smi · Job 进程 · 推理端口 │
└────────────────────────────────┘
```

| 角色 | 职责 | 不做什么 |
|------|------|----------|
| **主控** | 唯一控制面：配置、调度、探活、入口、鉴权、小助手 | 不要求本机有 GPU |
| **被控** | 跑 Job / 暴露推理；被主控 SSH 管理 | 不跑控制面 UI |
| **客户端** | 人 / Agent 访问主控 | 不直连改 `nodes.json` |

被控与主控的信任边界是 **SSH 密钥 + inventory**；客户端与主控的信任边界是 **鉴权**。

## 2. 访问路径（按推荐顺序）

| 场景 | 怎么连 `:8787` | 鉴权要求 | 典型用户 |
|------|----------------|----------|----------|
| A. 坐在主控上 | `http://127.0.0.1:8787` | 建议 password/OIDC；本机可自动读 Token | CodeLab / SSH 登录主控 |
| B. 笔记本 → 主控 | `ssh -N -L 8787:127.0.0.1:8787 <control>` 后访本机 8787 | 同 A | 日常运维 |
| C. IDE Remote SSH | 工作区在主控；插件 `apiBase=127.0.0.1:8787` | 自动读 `config/local/secrets/ui_api_token` | VS Code / Cursor / CodeLab |
| D. 团队内网 | Tailscale **serve**（仅 tailnet） | **必须** password 或 oidc | 多人共享 |
| E. 临时公网演示 | Tailscale funnel / Cloudflare quick | **强制**鉴权；`remote plan` 会阻塞未鉴权 | 演示 |
| F. 长期域名 | Cloudflare Tunnel + **Access（外层 SSO）** + 控制面 oidc/password | 双层：Access + 控制面 | 生产外网 |

**默认安全姿势**：UI 绑 `127.0.0.1` + 路径 A/B/C；需要集群外再上 D；公网只用 E 短时或 F。

端口转发不是「业务功能页」，而是 **把回环控制面接到人面前的管道**。配置 →「远程接入」负责 D/E/F；A/B/C 用 SSH / IDE 即可，页面里也会展示对应说明。

## 3. 鉴权矩阵

### 3.1 模式（`cluster.control.auth.mode`）

| 模式 | Web 登录 | API / MCP | 适用 |
|------|----------|-----------|------|
| `none` | 无 | 无 | 仅本机调试；`doctor` 会告警；**禁止**非回环绑定与公网 remote |
| `password` | Session Cookie | Bearer Token（`auth issue-token`） | 小团队默认 |
| `oidc` | 授权码 + PKCE → Session | 仍用 API Token（机器身份） | 企业 SSO / 统一登录 |

OIDC 可选 `allow_password_fallback`（默认关）；可用 **邮箱 / Groups** 白名单。

### 3.2 身份怎么用

| 调用方 | 凭证 | 存放 |
|--------|------|------|
| 浏览器 | Session Cookie（HttpOnly） | 浏览器；插件可存 SecretStorage |
| 脚本 / MCP / 插件 HTTP | `Authorization: Bearer` | `config/local/secrets/ui_api_token` 或 SecretStorage / 环境变量 |
| 被控节点 | 无控制面账号；靠 SSH | `nodes.json` · ansible key |

插件解析顺序（主控本机）：**本机 `ui_api_token` 文件 → SecretStorage → `GPU_CONTROL_API_TOKEN` 环境变量**。

### 3.3 未来 SSO（已定方向，不另起炉灶）

1. **控制面 SSO = OIDC**（已实现）：对接公司 IdP（Okta / Keycloak / 企业微信/飞书兼容 OIDC 等）。  
2. **边缘 SSO = Cloudflare Access / Tailscale ACL**（外层）：解决「谁能摸到域名」；**不替代**控制面鉴权。  
3. **不做**：自建账号系统、SAML-first（若 IdP 只提供 SAML，用网关转 OIDC）、把被控节点纳进 OIDC。  
4. **演进清单**（未做可排期）：IdP 预设模板、回调 URL 一键复制、OIDC 组 → 操作角色（只读 / 运维）、Token 按用途拆分（MCP 只读 vs 部署）。

## 4. 客户端约定

| 客户端 | 连法 | 完整看板 / 小助手 | 高频操作 |
|--------|------|-------------------|----------|
| Web | A–F | ✅ 唯一完整 UI（含助手 FAB、公告） | — |
| VS Code 插件 | 优先 C；否则 B + 改 `apiBase` | 用 Simple Browser / 平台打开代理 URL；**不要**在 CodeLab Webview 里硬嵌 `/proxy/8787` iframe（常 TCP 拒绝） | 工作台 / 集群树 / 终端 / 诊断 / 部署 |
| MCP Agent | HTTP + Token | 经 `gc_*` | 同 API |

### 4.1 CodeLab 要点（主控本机场景 C）

| 通道 | 走哪 | 免密？ | 说明 |
|------|------|--------|------|
| 插件树 / 工作台 / 命令 | 扩展宿主 → `127.0.0.1:8787` | ✅ 读 `ui_api_token` | 侧栏能刷集群即此通道正常 |
| 完整 Web 看板 | 浏览器 → CodeLab `…/proxy/8787/` | 否（Session / 再登录） | 用「接入说明 → Simple Browser / 平台打开」 |
| 被控节点 | 主控 SSH 出站 | ✅ 密钥 | 与 UI 密码无关 |

`asExternalUri(http://127.0.0.1:8787)` 会得到代理 URL；**代理 URL 在系统/Simple Browser 里往往可用，在扩展 Webview iframe 里常被拒**——这是 IDE 网络隔离，不是控制面挂了。

### 4.2 产品原则

插件提供 **工作台 + 接入说明**（讲清拓扑/鉴权）；完整看板/助手对话留在 Web，通过 Simple Browser / `openExternal(asExternalUri)` 打开，不在插件里再实现一套 UI，也不依赖 Webview iframe 嵌 `/proxy/8787`。

## 4.3 便捷 × 安全 × 性能（业界对齐后的取舍）

目标：**主控本机几乎零摩擦**；出网 / 多人 / 公网逐步加闸；**热路径不做 IdP 往返**。

### 四条凭证车道（参考 OpenShip / 常见 CLI）

| 车道 | 形态 | 谁用 | 性能 | 安全要点 |
|------|------|------|------|----------|
| **A. 回环免密** | 无 Cookie；仅内核 peer ∈ `{127.0.0.1,::1}` 且显式允许 | 桌面单机调试 | 最快 | **禁止**非回环绑定；peer 读 TCP，不信 `Host`/`X-Forwarded-For` |
| **B. 本机 PAT** | `ui_api_token` 文件 → Bearer | 插件 / MCP / 脚本（主控上） | 本地校验哈希，无外呼 | 文件权限 0600；可轮换；不进 URL/日志 |
| **C. 浏览器 Session** | HttpOnly Cookie（password / OIDC） | 完整 Web 看板 | 登录一次，之后本地验 Session | TTL 有上限；CSRF 仅写操作；禁 URL 长期 token |
| **D. 边缘身份** | Tailscale ACL / CF Access / 公司 SSO | 出网或多人 | 边缘终止，源站仍要 B/C | **外层不替代**控制面鉴权 |

ComputeDeck 现状：B + C +（OIDC∈C）+ D 的远程文档路径已具备；A 仅对应 `auth.mode=none` 且必须回环。

### 按场景的「又省事又稳」姿势

| 场景 | 推荐链路 | 为何又快又安全 |
|------|----------|----------------|
| CodeLab / Remote 坐在主控 | 插件走 **B**（自动读 Token）；看板用 **`openExternal(asExternalUri)` / Simple Browser** 走端口代理再走 **C** | API 热路径零 IdP；代理由 IDE 建隧，避免坏 iframe |
| 笔记本日常 | SSH `-L` 或 Tailscale **Serve** → 仍 **C/B** | 网络层收口到信任域，应用层不变 |
| 团队内网看板 | Serve（仅 tailnet）+ 控制面 password/OIDC | Serve 可带身份头，源站仍绑 localhost，防头伪造 |
| 长期公网 | CF Tunnel + **Access** + 控制面 OIDC | 双层：谁能摸到域名 ≠ 谁能调 API |
| 被控 GPU 机 | **只 SSH**，不上第二套账号 | 少一个爆炸面；性能即直连 |

### 明确不做 / 慎做

- **不做**：在 CodeLab Webview 里硬嵌 `/proxy/8787` 当主路径（隔离网络常 TCP 拒绝；业界也推 `asExternalUri` + `openExternal`）。
- **不做**：每个 API 请求打一遍公司 IdP（慢且脆）；OIDC 只在「换 Session」时发生。
- **不做**：把长期 Bearer 塞进 URL / 扫码二维码常驻（日志与 Referer 泄漏）。
- **慎做**：Funnel / 裸公网；必须先有强 C，且 `remote plan` 继续挡 `auth.mode=none`。
- **慎做**：mTLS 到浏览器用户；留给机器身份 / 设备策略，不作为小团队默认。

### 下一步可做的「便捷升级」（未实现，按收益排序）

1. **一键换票（推荐）**：插件已持有 PAT → `POST /api/auth/exchange` 发 **单次短 TTL code** → `openExternal` 打开 `/auth/consume?code=` → Web 换成 Session。人无感，票不进历史；比「再输一遍密码」顺，比「URL 长期 token」安全。  
2. **回环自动 Session**：仅当 peer 真是 loopback 且 mode 允许时，本地浏览器免登；**代理进来的请求不算回环**（CodeLab proxy 仍走换票或密码）。  
3. **Scoped Token**：`read` / `deploy` 拆分，MCP 默认只读，降低 Agent 误伤面。  
4. **设备码登录**（笔记本无隧道时）：对标 `gh auth login` device flow，浏览器在本机、CLI 在远端。  
5. **Serve 身份头**：团队内网时信任 Tailscale 用户头（源站必须 localhost），映射到只读/运维角色。

验收口诀：**插件热路径 = 本地 Bearer；人看大屏 = Session；出网 = 边缘身份 + 控制面身份；被控 = SSH。**

## 5. 交付与版本（含「要不要 npm」）

| 产物 | 渠道 | 说明 |
|------|------|------|
| 控制面 | 源码包 · GHCR 镜像 | 仓库即控制面 |
| 文档 | 控制面 `/help/` · 仓库 `docs/` | Pages 只放宣传展板 |
| VS Code 扩展 | **VSIX**（Release / 内网分发）；可选以后上 Open VSX | **不发 npm**：编辑器扩展标准单元是 VSIX，不是 npm 包 |
| Python | **不发 PyPI**（`package = false`） | 用仓库 / 镜像 |

版本四处对齐（发版时强制）：`VERSION` · `pyproject.toml` · `extensions/vscode/package.json` · `CHANGELOG.md` 的 `## [x.y.z]`。  
日常开发允许扩展 CHANGELOG 记 `1.2.x` 小步，**打 tag 前用 `prepare_release` 收束到同一版本号**。

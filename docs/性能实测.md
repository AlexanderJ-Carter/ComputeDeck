# 性能实测

本机控制面数字（2026-11-15 · macOS arm64 · Python 3.11 · `0.21.0`）。UI 在 loopback 拉起，**未**接真实 GPU worker；跨机 SSH / 训练吞吐不在此列。

对标用来建立量级感：同机、同日测得的本机基线，或常见体感阈值。

## 启动与质量门禁

| 指标 | ComputeDeck | 对标 | 怎么读 |
|------|-------------|------|--------|
| UI 就绪（`ui --background` → `/api/health`） | **~77 ms** | 空进程 `python -c pass` 约 **17 ms**；人眼一眨眼约 **100–400 ms** | 大约 4–5 个空 Python 进程的时间，通常小于一次眨眼 |
| `./scripts/check.sh` | **0.50 s** 全过 | 常见 CI 门禁动辄数十秒到数分钟 | 本机改完就能秒级确认语法、18 单测与 UI 静态审计 |
| 单测 | **18** 项 / **~9 ms** | — | 状态写、端点、Job 安装、WebSocket 帧等核心路径 |

## API 延迟（loopback · 预热后 30 次）

同机对照：stdlib 最小 HTTP（只回 `{"ok":true}`）health p50 **0.27 ms**。

| 接口 | p50 | 相对最小 HTTP | 含义 |
|------|-----|---------------|------|
| `GET /api/health` | **0.61 ms** | ≈ **2.3×** | 带版本号的健康检查，仍远低于 1 ms |
| `GET /api` 能力目录 | **0.58 ms** | ≈ **2.1×** | ~11 KB JSON，和 health 同量级 |
| `GET /api/openapi.json` | **0.79 ms** | ≈ **2.9×** | ~24 KB 完整契约 |
| `GET /api/overview?light=1` | **0.68 ms** | ≈ **2.5×** | 看板轮询；体量约全量的 **43%**（7 KB / 17 KB） |
| `GET /api/overview` | **0.96 ms** | ≈ **3.6×** | 全量总览；比 light 大约 **+41%** 延迟 |
| `GET /api/jobs` | **1.56 ms** | ≈ **5.8×** | 含模板扫描 |
| `GET /api/doctor` | **~84 ms** | — | 本地配置自检，不是热路径轮询 |

20 路并发打 `overview?light=1`：整批墙钟中位 **~41 ms**（均摊约 **2.1 ms**/请求），相当于本机约 **~500 次/秒** 量级的轮询能力（单机 loopback，不含鉴权与 SSH）。

## 体量与能力面

| 指标 | ComputeDeck | 对标 | 怎么读 |
|------|-------------|------|--------|
| 源码树（无 `.venv`） | **~2.3 MB** | 仅内置 xterm 就 **~393 KB** | 控制台不依赖外网 CDN，内网可直接打开终端 |
| OpenAPI | **69** path / **73** 操作 | 纯脚本机房通常 **0** 条机器可读契约 | Agent / 脚本可按目录调用，不必翻人肉手册 |
| MCP | **15** 个 `gc_*` | 多数自建脚本栈 **无** MCP | Cursor 等可直接腾空、改配置、启停 Job |
| Job 模板 | **11** | 自建常是「每个业务一份互不相通的 shell」 | 训练 / vLLM / Ray / Docker 走同一套安装与租约 |
| CLI 子命令 | **18** | — | 与 HTTP / MCP 同一能力面 |

## 复现

```bash
uv venv .venv && uv pip install -r requirements.txt
cp -n config/examples/cluster.example.json config/local/cluster.json
cp -n config/examples/nodes.example.json config/local/nodes.json
./scripts/check.sh
gpu-control ui --background
curl -o /dev/null -s -w '%{time_total}\n' http://127.0.0.1:8787/api/health
```

接上真实 worker 后，overview / doctor 会叠加 SSH 与采集时间，建议在目标机房按同样表格再测一版。

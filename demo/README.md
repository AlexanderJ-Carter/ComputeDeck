# ComputeDeck 宣传展板

全屏纵向 scroll-snap 演示页（中文），适合投屏与 GitHub Pages。

## 本地预览

```bash
cd demo
python3 -m http.server 4173
# http://127.0.0.1:4173/
```

## GitHub Pages

仓库 Actions 工作流 `.github/workflows/pages.yml` 会把本目录发布到 Pages。  
启用后地址形如：

`https://alexanderj-carter.github.io/ComputeDeck/`

产品名 **ComputeDeck**；命令行仍为 `gpu-control`。
